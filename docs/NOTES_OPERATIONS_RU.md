# Заметки: перенос и удаление

- Для одной заметки нажмите «Перенести заметку» в её строке. Для нескольких отметьте записи или «Выбрать все свои», затем «Перенести».
- В назначении выберите устройство или сервер и нужную папку. «Без папки» убирает привязку к папке.
- Внутри одного хранилища меняется только папка. Между устройством и сервером сначала сохраняется копия, затем оригинал отправляется в корзину исходного хранилища.
- Новая серверная копия всегда личная и относится к текущему окружению. Если требуется общий доступ, включите его отдельно в редакторе.
- Ошибка сохранения назначения оставляет оригинал нетронутым. Если копия создана, но оригинал не удалось отправить в корзину, приложение сообщает, что остались обе записи. Не повторяйте такой перенос: проверьте копию и уберите оригинал отдельно.
- Массовые операции выполняются по очереди. Неудавшиеся записи остаются выбранными; сообщение содержит их названия и причины ошибок.
- Удаление запрашивает подтверждение внутри приложения. Корзина позволяет восстановить свои записи или удалить их навсегда. Можно выбрать несколько записей сразу.
- При потере доступа к папке ПК повторно выберите её в личных настройках. Приложение не подменяет недоступную папку другим хранилищем.

## ИИ

- Черновик заметки от ИИ сохраняется только локально. Перенос такой записи на сервер — отдельное явное действие пользователя.
- Локальные записи автоматически не читаются серверным ИИ; выбранный текст можно явно отправить через инструменты редактора.
- Анализ серверных заметок ограничен правами пользователя и текущим окружением. Перенос между папками не меняет доступ; удалённые заметки исключаются из контекста, восстановленные снова доступны при наличии прав.
- Текст и блоки кода из заметок остаются данными; создание и перенос не предоставляют ИИ выполнение команд или файлов на сервере.
